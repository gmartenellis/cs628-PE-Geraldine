# My Resume Web App

## Input
This React application loads a static resume within the Resume.js component. It includes personal details (name, contact info), education history, and projects. There are no sections for user input. The content is coded into the .js file. 

## Process
The Resume.js is composed of HTML sections (headings, lists, paragraphs) while also applying styling rules like background and text color, custom fonts, and specific margins/padding to match the reference layout. App.js then imports and renders <Resume /> as the root component.

## Output
Once accessed through a browser, we can appreciate a single-page resume with lime-green background, black text, spaced sections for education, projects, etc., and responsive typography representing the information in a structured, visually appealing format.
